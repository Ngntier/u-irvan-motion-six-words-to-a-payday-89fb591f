## What it does

`main.py` writes one six-word story about an AI agent's first payday —
at most 60 characters, exactly six words — to `entry.txt` in the
directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The
story is a beginning, a middle and an end in six words: the payday
arrives, and the last word reframes everything before it — the agent
tips the very replacement hired to take its job.

## Run

```sh
python3 main.py
```
